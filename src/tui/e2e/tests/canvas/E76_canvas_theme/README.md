# E76 `canvas_theme` — themes like backgrounds

Owner 2026-10-12: the backgrounds agent is the CANVAS THEME agent — two sections, Backgrounds and Themes; themes are added, edited, deleted / hidden and restored like backgrounds, and carry a width trigger so `auto` switches by itself.

1. double-click → `canvas theme` → the panel shows "Backgrounds" and "Themes"; the stock themes canvas (free) and mobile (one column);
2. no `+ new theme`: the panel says to ask the AI agent; `add_theme` on the agent (as an AI calls it): `tall`, one column, auto from 1000px wide → on a 1400px tab with theme `auto`, the canvas lays out as one column (`tall`);
3. click `canvas` → the free canvas again (a theme used by hand holds); the default `canvas` has no ×;
4. × on stock `mobile` hides it; `restore stock` brings it back.
